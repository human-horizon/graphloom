# Ускорение анализа

## Контекст

Анализ большого проекта долго выполняется, а интерфейс показывает только общее состояние
«Анализирую». OpenAI-запрос не ограничивает размер ответа, поэтому Qwen 9B может долго
генерировать JSON.

## Цель

Сократить время LLM-этапа и сделать ожидание понятным:
- карта проекта — максимум 4096 output tokens;
- flow функции — максимум 8192 output tokens;
- сетевой запрос не может зависнуть бесконечно;
- UI показывает, что сейчас выполняется AI-анализ.

## Что изменится

1. `src-tauri/src/llm.rs` — `max_tokens` и timeout клиента.
2. `src-tauri/src/pipeline.rs` — разные лимиты для project/function generation.
3. `src/screens/Reports.tsx` — понятный статус во время анализа.

## Критерии приёмки

- [ ] Mock-E2E и cargo test проходят.
- [ ] clippy и typecheck проходят.
- [ ] В запрос project map передаётся `max_tokens: 4096`.
- [ ] В запрос function flow передаётся `max_tokens: 8192`.
- [ ] При анализе UI показывает понятный статус, а не только бесконечное ожидание.
