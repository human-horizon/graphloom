# Улучшение схем и навигации renderer

## Контекст

Сейчас схемы Graphloom выглядят перегруженно: узлы имеют много свободного пространства, связи плохо читаются, а для больших деревьев неудобно перемещаться. Renderer не предоставляет зум и панорамирование, поэтому пользователь не может удобно рассматривать большие схемы.

## Цель

Сделать схемы компактными и читаемыми как вертикальный поток сверху вниз, а также добавить полноценную навигацию по полотну: зум колесом или трекпадом вокруг курсора, панорамирование мышью и панель управления масштабом.

## Что изменится

1. `src-tauri/src/render.html` — визуальная система схем, SVG-трансформация, зум, панорамирование, управление viewport и обработка событий.
2. `src-tauri/tests/e2e.rs` — проверки наличия новой навигации и визуальных стилей в отчёте.
3. `PROJECT_CONTEXT.md` — запись о найденных проблемах и решении.

## Детали реализации

1. Добавить viewport-состояние renderer:
   - масштаб с ограничением `0.25..2.5`;
   - смещение по осям X/Y;
   - начальное масштабирование `Вписать` для текущей схемы.
2. Рендерить связи и узлы внутри общей SVG-группы с трансформацией `translate(x y) scale(scale)`.
3. Реализовать управление:
   - колесо или трекпад — масштабирование вокруг позиции курсора;
   - перетаскивание пустого места — панорамирование;
   - `Space` + перетаскивание — панорамирование независимо от положения курсора;
   - кнопки `+`, `−`, `100%`, `Вписать`;
   - `0` — вписать схему, `1` — вернуть масштаб 100%.
4. Разделить действия по клику:
   - обычный клик по ноде открывает sidebar с описанием, связями и исходным кодом;
   - `⌘ + click` открывает дочернюю схему или выполняет переход к символу/файлу;
   - завершившееся панорамирование не открывает sidebar.
5. Не ломать клики по узлам, sidebar и переходы по символам после трансформации SVG.
5. Улучшить внешний вид:
   - уменьшить избыточные размеры карточек;
   - расположить scope-ноды в одной вертикальной колонке сверху вниз по порядку исходника;
   - добавить визуальное различие корневых, групповых, call- и decision-узлов;
   - сделать связи менее доминирующими и направить их вертикально;
   - выровнять подписи и ограничить переполнение длинного текста;
   - сохранить тёмную тему и Lucide/SVG-иконки без emoji.
6. Для больших схем сохранить прокрутку и не сбрасывать viewport при обычном поиске или переключении слоёв без необходимости.
7. Добавить в renderer безопасное поведение для пустых схем и недоступных размеров viewport.

## Критерии приёмки

- [ ] Колесо/трекпад изменяет масштаб вокруг курсора.
- [ ] Пустое место можно перетаскивать для панорамирования.
- [ ] `Space` + drag также панорамирует схему.
- [ ] Кнопки `+`, `−`, `100%`, `Вписать` работают.
- [ ] Обычный клик по ноде открывает sidebar с кодом.
- [ ] `⌘ + click` выполняет переход к дочерней схеме или символу.
- [ ] Клики по узлам, sidebar и навигация по символам работают при любом масштабе.
- [ ] Большая схема стартует в вписанном масштабе и не оказывается за пределами viewport.
- [ ] Scope-ноды идут одной колонкой сверху вниз в порядке исходника.
- [ ] После `⌘ + click` доступна кнопка возврата к предыдущему отчёту.
- [ ] Карточки и связи читаются компактнее, чем до изменения.
- [ ] Проходят `cargo test`, `cargo clippy --all-targets -- -D warnings`, `pnpm typecheck`, `pnpm build`.
- [ ] После изменений выполнен `./scripts/install-mac.sh`.
