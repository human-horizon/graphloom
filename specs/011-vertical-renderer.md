# Вертикальный renderer диаграмм

## Контекст

HTML-диаграмма сейчас строится горизонтальными слоями. Узлы уходят за правую границу, а
header canvas выглядит как большая чёрная плашка: легенда переносится вертикально и занимает
пространство над схемой.

## Цель

Сделать диаграмму вертикальным flow сверху вниз, оставив header компактным и не перекрывающим
схему.

## Изменения

- `src-tauri/src/render.rs` — вертикальное позиционирование, вертикальные SVG-связи,
  компактный canvas header и корректные размеры SVG.
- `src-tauri/tests/e2e.rs` или unit tests — проверить self-contained renderer и наличие
  вертикальной схемы в HTML.

## Критерии приёмки

- [x] Узлы располагаются сверху вниз по слоям.
- [x] Связи направлены вертикально от нижней грани к верхней.
- [x] Legend отображается одной строкой и не создаёт высокий overlay.
- [x] Search и navigation находятся в компактном header.
- [x] SVG получает высоту по вертикальному layout.
- [x] `cargo test`, `clippy`, `pnpm typecheck`, `pnpm build` проходят.
- [x] Graphloom.app переустановлен в `/Applications`.
