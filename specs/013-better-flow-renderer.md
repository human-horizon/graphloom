# 013 — Улучшенный flow-renderer

## Проблема
Текущая вертикальная схема выглядит примитивно:
- текст в узлах обрезается,
- подписи рёбер наезжают на узлы и друг на друга,
- нет понятного порядка чтения,
- ромб решения перегружен,
- все узлы одной формы и цвета не несут семантики.

## Цель
Сделать HTML-отчёт таким, чтобы его можно было показать на ревью: читаемые карточки, явный порядок шагов, различимые формы узлов, чистые подписи рёбер.

## Решение
### 1. Формы узлов
- **Терминатор (капсула)** — узлы без входящих (старт) или без исходящих (стоп/ошибка/вывод).
- **Процесс (скруглённый прямоугольник)** — обычные шаги.
- **Решение (ромб)** — `kind === "decision"`.

### 2. Размеры по содержимому
- Авто-ширина карточки: min 180px, max 320px.
- Label переносится по словам, не обрезается.
- Summary отображается мелким серым текстом под label.
- Высота карточки зависит от количества строк.

### 3. Нумерация шагов
- Каждому видимому узлу присваивается порядковый номер `1, 2, 3…` сверху вниз, слева направо.
- Номер рисуется в небольшом круге в левом верхнем углу карточки.

### 4. Рёбра и подписи
- Связь выходит из нижнего центра источника и входит в верхний центр цели.
- Плавная кривая Безье с минимумом изгибов.
- Подпись ребра рисуется в плашке с тёмным фоном и обводкой, чтобы не пересекалась со линией.
- Позиция плашки — середина кривой, вычисленная через `getPointAtLength`.

### 5. Layout
- Динамический слоистый layout: узлы группируются по слоям, внутри слоя располагаются слева направо с отступом 40px.
- Горизонтальный слой центрируется по ширине самого широкого слоя.
- Вертикальный отступ между слоями зависит от максимальной высоты предыдущего слоя + 60px.

### 6. Внешний вид
- Иконка слева внутри карточки, цвет соответствует типу элемента.
- Цвет рамки — из палитры / дефолтный по kind.
- При наведении карточка слегка светлеет.
- Search и слои остаются без изменений.

## Изменения
- Новый файл `src-tauri/src/render.html` с полным HTML/JS/CSS шаблоном.
- `src-tauri/src/render.rs` читает шаблон через `include_str!("render.html")`.
- Тесты `render.rs` и `e2e.rs` обновлены: убран хардкод `p1.x + 95`, добавлены проверки на наличие элементов улучшенного рендерера.
