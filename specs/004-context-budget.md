# Контекстный бюджет LLM

## Контекст

Большой проект отправлял полный UCM вместе с промптом и few-shot примером. Запрос достиг
99183 токенов при доступном контексте 65536 и получил HTTP 400.

## Цель

Сохранить полный статический анализ локально, но передавать модели только релевантную
компактную проекцию UCM:

- карта проекта — пакеты, компактные символы, уникальные связи и эффекты;
- flow функции — выбранный символ, прямые callees, их связи и эффекты.

Исходный код не усекается: для flow передаются полные исходники выбранной функции и
прямых callees.

## Что изменится

1. `src-tauri/src/pipeline.rs` — сериализуемые компактные контексты `ProjectContext` и
   `FunctionContext`; полная UCM-модель остаётся для валидации и кэша.
2. `src-tauri/src/llm.rs` — понятная ошибка при превышении контекста.
3. `src-tauri/src/pipeline.rs` — промпт карты и flow используют компактный контекст.

## Критерии приёмки

- [ ] Большой проект не отправляет полный UCM в LLM.
- [ ] `cargo test`, `cargo clippy -- -D warnings`, `pnpm typecheck` проходят.
- [ ] Mock-E2E карты и flow проходят.
- [ ] Живой запрос к home-pc на большом проекте больше не получает ошибку context size.
