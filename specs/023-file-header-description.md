# Описание файла в заголовке отчёта

## Контекст

В file-level отчёте файл сейчас является корневым `group`-узлом с дочерними функциями. Из-за этого файл визуально становится областью диаграммы, а структурные/внешние связи могут восприниматься как связи с самим файлом. Файл должен быть контекстом отчёта, а не узлом архитектурного flow.

## Цель

Убрать файл из SVG-диаграммы и показывать его `label` и `summary` в верхнем сообщении renderer. Функции файла должны остаться независимыми сворачиваемыми узлами; связи к file node не должны отображаться.

## Что изменится

1. `src-tauri/src/render.html` — file-level root превращается в метаданные заголовка; layout строится по дочерним узлам, без file region и file edges; label/summary выводятся сверху.
2. `src-tauri/src/render.rs` — проверки поведения file header в renderer-шаблоне.
3. `specs/023-file-header-description.md` — критерии и результаты выполнения.

## Детали реализации

1. В `treeLayout` определить file-level root как `nodes[0]` с `source.file` и дочерними узлами. Извлечь его `label` и `summary` в объект `header`.
2. Для file-level layout использовать дочерние узлы root как независимые top-level nodes. Сам root не добавлять в `visible`, `metrics`, `regions` или structural arcs.
3. Не переносить edges на file root: edges с endpoint file node отбрасывать. Связи между функциями и другими видимыми узлами сохранять только если они присутствуют в DSL и не являются искусственной связью файла.
4. Не строить scope-region для file root. Области функций и вложенных составных блоков сохранять.
5. В верхней панели renderer добавить отдельный `file-description` блок: показывать label файла и summary файла одновременно. Если summary отсутствует, показывать только label; если label отсутствует, использовать имя файла из `source.file`.
6. При навигации в дочерний function view блок описания должен обновляться согласно текущему view и не создавать новый внешний edge.
7. Сохранить collapse toggle, обычный клик/sidebar, `⌘ + click`, поиск и native scroll.

## Критерии приёмки

- [x] File node отсутствует в SVG file-level отчёта.
- [x] File node не создаёт scope-region.
- [x] Внешние связи к file node не отображаются.
- [x] Label и summary файла одновременно видны в верхнем сообщении renderer.
- [x] Функции остаются отдельными сворачиваемыми узлами без искусственной цепочки.
- [x] Сворачивание функции сохраняет её внешние связи.
- [x] Навигация, sidebar, поиск и native scroll продолжают работать.
- [x] `cargo test`, `cargo clippy --all-targets -- -D warnings`, `CI=true pnpm typecheck` и `CI=true pnpm build` проходят.
- [x] Graphloom переустановлен, file-level отчёт проверен визуально.
