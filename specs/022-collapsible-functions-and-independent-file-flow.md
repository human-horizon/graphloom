# Сворачиваемые функции и независимые функции в file flow

## Контекст

В renderer функция отображается как `group`-узел с дочерними блоками, но отдельного управления сворачиванием нет. Кроме того, `treeLayout` соединяет все узлы одного дерева в единую последовательную цепочку. Поэтому соседние функции в одном файле, особенно в `main.go`, выглядят как последовательные шаги, хотя они являются отдельными сущностями.

## Цель

Добавить сворачивание и разворачивание каждой функции непосредственно на её узле. При сворачивании скрываются только внутренние узлы функции, а сама функция остаётся видимой; внешние связи направляются на её заголовок. В file-level дереве соседние функции не должны соединяться искусственной цепочкой.

## Что изменится

1. `src-tauri/src/render.html` — состояние сворачивания, кнопка на узле, фильтрация скрытых поддеревьев, сохранение внешних связей и новый алгоритм структурных связей дерева.
2. `src-tauri/src/render.rs` — проверки обязательных частей renderer-шаблона.
3. `src-tauri/src/semantic.rs` — unit-тесты/поддержка ожидаемой независимой структуры узлов, если для этого потребуется изменение DSL-построения.
4. `specs/022-collapsible-functions-and-independent-file-flow.md` — критерии и результаты выполнения.

## Детали реализации

1. В renderer завести множество `collapsedNodes`, индексируемое стабильным `node.id`.
2. Для `group`-узлов с непустыми `children` отрисовывать компактный toggle-контрол `−`/`+`. Клик по нему не открывает sidebar и не запускает навигацию; он меняет состояние и перерисовывает текущий view.
3. `treeLayout` при свёрнутой функции оставляет узел функции в `visible`, но не добавляет её потомков в layout. Для развёрнутого узла поведение сохраняется.
4. Строить structural arcs по иерархии `parent → child`, а не по глобальному порядку плоского массива. Это гарантирует, что функции-сёстры в `main.go` не получают связи `функция A → функция B`.
5. Для узлов, которые скрыты сворачиванием, внешние DSL edges не удалять: endpoint скрытого потомка поднимать к ближайшему видимому свёрнутому предку. Если связь уже начинается/заканчивается на заголовке функции, оставить её без изменений. Дубликаты после подъёма удалять.
6. При разворачивании восстанавливать исходные узлы и связи без изменения DSL/данных отчёта. Состояние действует только в текущем HTML report view.
7. Сохранить обычный клик по узлу для sidebar и `⌘ + click` для существующей навигации.

## Критерии приёмки

- [x] У function/group-узла с дочерними узлами есть видимый toggle `−`/`+`.
- [x] Сворачивание скрывает дочерние узлы и их внутренние structural edges, но оставляет заголовок функции.
- [x] Внешняя связь скрытого поддерева отображается на видимом заголовке функции и не дублируется.
- [x] В file-level дереве две соседние функции не соединены искусственной последовательной связью.
- [x] Разворачивание возвращает все дочерние узлы и связи.
- [x] Обычный клик, `⌘ + click`, sidebar, поиск и native scroll продолжают работать.
- [x] `cargo test`, `cargo clippy --all-targets -- -D warnings`, `CI=true pnpm typecheck` и `CI=true pnpm build` проходят.
- [x] Graphloom переустановлен, а поведение проверено в установленном приложении.
