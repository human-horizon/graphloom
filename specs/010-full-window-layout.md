# Полнооконный layout

## Контекст

После установки приложения рабочая область ограничена `max-width`, имеет большие боковые и
нижние отступы. Кнопка меню находится в левом верхнем углу и занимает заметное место.

## Цель

Использовать всю площадь окна для дерева и диаграммы, закрепить панель действий сверху и
перенести меню в компактную кнопку справа.

## Изменения

- `src/App.tsx` — меню справа сверху.
- `src/index.css` — полноширинный content, sticky toolbar, viewport-height report layout,
  компактные отступы и растягивание canvas.
- `src-tauri/tauri.conf.json` — приложение стартует максимизированным, без принудительного
  fullscreen режима; системная шапка macOS сохраняется.

## Критерии приёмки

- [x] Рабочая область использует всю ширину окна.
- [x] Дерево и canvas занимают доступную высоту до нижнего края окна.
- [x] Внешний scrollbar приложения отсутствует; прокручиваются только внутренние области.
- [x] Toolbar закреплён сверху при прокрутке.
- [x] Меню находится в маленькой кнопке справа сверху.
- [x] Приложение стартует максимизированным.
- [x] `pnpm typecheck`, `pnpm build`, `cargo test`, `clippy` проходят.
- [x] Обновлённый `.app` установлен в `/Applications`.
