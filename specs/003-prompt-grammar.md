# Грамматическая проверка подписей LLM

## Контекст

После few-shot промптов qwen-3.5-9b строит смысловые подписи, но иногда допускает
неестественные конструкции вроде «Запустить отправка email».

## Цель

Заставить модель выдавать грамматически корректные русские подписи и summaries,
особенно для действий, эффектов, решений и веток.

## Что изменится

1. `src-tauri/prompts/project_map.md` — правила грамматической самопроверки для labels и summaries.
2. `src-tauri/prompts/function_flow.md` — правила согласования, формы инфинитива и few-shot
   примеры исправления неестественных фраз.

## Детали реализации

- Действия формулируются естественным инфинитивом: «Отправить письмо», «Сохранить пользователя».
- После глагола использовать правильный падеж: «Запустить отправку», не «Запустить отправка».
- Для решений использовать короткие вопросы: «Данные валидны?», «Имя заполнено?».
- Перед JSON-ответом модель делает внутреннюю проверку: подпись нельзя дословно копировать
  из идентификатора; согласование и падежи должны быть корректны.
- Добавить явные пары BAD/GOOD, включая «Запустить отправка email» → «Запустить отправку
  приветственного письма».

## Критерии приёмки

- [x] Mock-E2E, cargo test и clippy проходят.
- [x] Живой flow-тест проходит (живой прогон с этими промптами: 9 узлов, 10 связей).
- [x] В живом flow-отчёте нет фразы «Запустить отправка»; получено «Запустить фоновую отправку email».
  Assertion добавлен в `tests/live.rs`; повторный сетевой прогон после этого был остановлен из-за зависшего ответа endpoint.
