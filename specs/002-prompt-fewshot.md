# Усиление LLM-промптов + few-shot примеры

## Контекст

Живой тест на qwen-3.5-9b (home-pc) показал: DSL структурно валиден, но подписи
буквальные («CreateUser» вместо «Создать пользователя») — модель игнорирует требование
смысловых подписей. Промпты размазаны по коду в `pipeline.rs`, редактировать их неудобно.

## Цель

Вынести промпты в файлы с few-shot примерами, явно запретить копирование идентификаторов
в подписи. Качество проверяется живым тестом: подписи становятся смысловыми фразами.

## Что изменится

1. `src-tauri/prompts/project_map.md` — системный промпт карты проекта + few-shot
   (мини-UCM → идеальный DSL с семантическими подписями).
2. `src-tauri/prompts/function_flow.md` — то же для flow функции.
3. `src-tauri/src/llm.rs` — загрузка шаблонов (`include_str!`), подстановка
   `{{PALETTE}}` и `{{SCHEMA}}`.
4. `src-tauri/src/pipeline.rs` — использование шаблонов вместо инлайн-промптов.

## Детали реализации

- Плейсхолдеры: `{{PALETTE}}`, `{{SCHEMA}}` — простой `str::replace`.
- Ключевые правила в обоих промптах:
  - `label` — смысловая фраза на русском, описывающая назначение («Сохранить пользователя
    в БД»), а не идентификатор. Запрещено копировать имя символа как есть.
  - Все `source.file`, `symbol` — только из UCM, ничего не выдумывать.
  - Ответ — строго JSON по схеме, без markdown.
- Few-shot: в `project_map.md` пример с пакетом `internal/user` (CreateUser/parseName/
  validateName/DB.Save/sendEmail) → узлы «Управление пользователями», «Хранилище
  пользователей» и т.п.; в `function_flow.md` — пример flow с decision «Данные валидны?».
- Промпты на английском (инструкции), подписи — на русском (явное указание).

## Критерии приёмки

- [x] `cargo test` (unit + E2E с mock) — зелёные (маркеры «PROJECT-level»/«FUNCTION-level» сохранены в промптах)
- [x] `cargo clippy` — чисто
- [x] Живой тест `cargo test --test live -- --ignored` проходит (карта + flow, 70с)
- [x] В живом отчёте подписи — смысловые: «Извлечь имя из входных данных», «Имя валидно?», «Сохранить пользователя в БД»; связь карты проекта осталась verified
