# Полупрозрачные области вложенных блоков

## Контекст

В вертикальном tree-layout все ноды находятся в одной колонке и визуально выглядят как плоская последовательность. Хотя связи сохраняют порядок выполнения, по схеме трудно понять, какие ноды входят в `if`, цикл, функцию или другой составной блок.

## Цель

Показать иерархию всех составных блоков через рекурсивные полупрозрачные области, охватывающие родительскую ноду и её потомков.

## Что изменится

1. `src-tauri/src/render.html` — tree-layout вычисляет глубину и границы scope-областей, ноды получают отступ по уровню, области рисуются позади связей и нод.
2. `src-tauri/src/render.rs` — проверки шаблона подтверждают наличие scope-region разметки.

## Детали реализации

1. Для каждого узла с непустым `children` вычислять границы по всей рекурсивной ветке, включая сам узел.
2. Рисовать область как `<rect>` со скруглёнными углами, прозрачной заливкой цвета родительской ноды и тонкой полупрозрачной рамкой.
3. Вложенные области рисовать рекурсивно; родительская область должна охватывать дочерние области, но не закрывать связи и текст.
4. Сдвигать ноды вправо пропорционально глубине, чтобы границы областей не выглядели одной общей колонкой.
5. Области не должны перехватывать клики; текущая навигация, sidebar, поиск и native scroll сохраняются.
6. Размер SVG должен учитывать границы областей, чтобы они не обрезались при прокрутке.

## Критерии приёмки

- [x] Вложенная область полностью находится внутри области родителя.
- [x] Ноды разных уровней имеют визуальный горизонтальный отступ.
- [x] Области находятся позади связей и нод и не ломают клики.
